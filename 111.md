# WebWorld BetBot Beta Prototype

Этот репозиторий содержит документацию и планы для Beta-прототипа автоматизированного веб-агента, предназначенного для анализа спортивных событий (в частности, мужского тенниса ATP) и выполнения букмекерских ставок на основе анализа.

## 🎯 Концепция <a name="concept"></a>

Цель прототипа - создать систему, которая:

1.  **Интерпретирует веб-страницы:** Использует модель мира для веба (WebWorld) для анализа состояния букмекерских сайтов.
2.  **Анализирует события:** Использует внешнюю модель (например, `qwen-coder`) для получения данных из интернета и анализа спортивной статистики (например, матчей тенниса ATP) с целью определения потенциального исхода (например, победы фаворита).
3.  **Выполняет действия:** Использует Selenium для автоматического выполнения действий на веб-сайте (навигация, выбор ставки, ввод суммы, подтверждение).
4.  **Интегрирует компоненты:** Объединяет вышеупомянутые компоненты в единый рабочий процесс с помощью Python-скрипта-агента.

## 🔧 Компоненты <a name="components"></a>

- **WebWorld (дообученная):**
    - **Роль:** Модель мира для веб-агента. Планирование веб-взаимодействий, понимание структуры страниц.
    - **Функции:**
        - Анализ состояния страницы (A11y Tree, HTML).
        - Генерация веб-действий (`click`, `fill`).
        - Использование `send_msg_to_user` для запроса внешней информации.
- **`qwen-coder` (или другая внешняя модель/инструмент):**
    - **Роль:** Модель анализа и принятия решений.
    - **Функции:**
        - Получение данных из интернета (статистика тенниса).
        - Анализ данных и прогнозирование исхода матча.
        - Принятие решения о ставке (на кого, сколько).
- **Selenium:**
    - **Роль:** Инструмент для автоматизации браузера.
    - **Функции:**
        - Открытие и навигация по веб-сайтам.
        - Выполнение физических действий (клик, ввод текста), указанных WebWorld.
- **Python-скрипт-агента:**
    - **Роль:** Основной управляющий элемент, связывающий все компоненты.
    - **Функции:**
        - Управление циклом: захват состояния -> вызов WebWorld -> интерпретация вывода WebWorld -> вызов `qwen-coder` (при необходимости) -> выполнение действий через Selenium.

## 🚀 План Действий <a name="plan"></a>

1.  **Скачивание:**
    - Модель WebWorld (например, `WebWorld-8B`).
    - Датасет `WebWorldData`.
2.  **Подготовка данных:**
    - Изучение формата `WebWorldData` (JSONL, разговоры).
    - Перевод данных WebWorldData на **русский язык** с использованием `qwen-coder`.
    - Ручная проверка качества перевода, особенно структуры A11y Tree и синтаксиса действий.
    - Подготовка **собственных данных**, описывающих:
        - Взаимодействия с русскоязычными веб-сайтами.
        - Сценарии, включающие вызов внешней модели анализа (например, `send_msg_to_user("Нужна статистика...")` -> вызов `qwen-coder` -> получение результата).
    - Объединение переведенного `WebWorldData` и собственных данных.
3.  **Fine-tuning:**
    - Дообучение выбранной модели WebWorld (например, `WebWorld-8B`) на объединенном русскоязычном датасете.
4.  **Разработка агента:**
    - Создание Python-скрипта, реализующего логику агента.
    - Интеграция вызовов дообученной модели WebWorld.
    - Интеграция вызовов `qwen-coder` для анализа теннисных матчей.
    - Интеграция Selenium для выполнения веб-действий.
    - Реализация логики обработки `send_msg_to_user` и возврата результатов анализа в контекст WebWorld.

## ✅ Возможности <a name="capabilities"></a>

- Автоматизированная навигация по веб-сайтам букмекерских контор.
- Чтение и интерпретация информации на страницах (коэффициенты, события).
- Интеграция с внешними источниками данных и аналитическими моделями.
- Возможность выполнения последовательных действий (например, найти матч -> выбрать ставку -> ввести сумму -> подтвердить).
- Возможность адаптации к русскоязычным интерфейсам.

## ⚠️ Ограничения <a name="limitations"></a>

- **Точность прогнозов:** Успех системы *напрямую зависит* от способности *внешней модели анализа* (например, `qwen-coder`) давать точные прогнозы. Современные LLM не идеальны для строгого вероятностного анализа.
- **Надежность WebWorld:** Модель может ошибаться в понимании сложных или динамических страниц.
- **Ограничения со стороны сервисов:** Букмекерские конторы могут ограничивать или блокировать аккаунты, использующие автоматизацию.
- **Юридические аспекты:** Использование автоматизации для ставок может нарушать правила платформ и законы.
- **Сложность реализации:** Интеграция нескольких сложных систем требует значительных технических усилий и настройки.
